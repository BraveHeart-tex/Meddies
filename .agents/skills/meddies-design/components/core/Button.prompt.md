Rounded, heavy-label button — use for every tappable action; exactly one `primary` per view.

```jsx
<Button icon="check" fullWidth>Taken</Button>
<Button variant="secondary">Skip</Button>
<Button size="xl" fullWidth>Save as taken</Button>
<Button size="md" pill icon="plus">Add</Button>
```

Variants: primary (berry), secondary (white + border), soft (blush, berry text), ghost (Cancel). Sizes sm/md/lg/xl = 36/46/52/56px. Press = darker fill + 0.98 scale; no bounce.
