Status pill for doses and stock — always icon + words.

```jsx
<StatusBadge status="taken" time="09:12" />
<StatusBadge status="notLogged" />
<StatusBadge status="scheduled" />
<StatusBadge status="skipped" />
<StatusBadge status="low" label="8 left" size="sm" />
```

taken = sage + check · notLogged = amber + dashed ring · scheduled = outline + clock · skipped = cream + slashed ring · low = amber + triangle.
