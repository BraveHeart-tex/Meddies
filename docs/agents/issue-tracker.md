# Issue Tracker

Issues live in Linear. Use the `linearis` skill and CLI.

## Workflow

- Follow the `linearis` skill's discovery and authentication instructions.
- Read issues and discussions before changing them.
- Reference tickets by their Linear identifier.
- Resolve the team and project from the task or existing Linear records.
  Ask when the destination remains ambiguous.
- Create and update issues in Linear.
- Record non-trivial progress in issue discussions and keep descriptions
  consistent with status changes.
- Use `docs/agents/triage-labels.md` for triage label names.
