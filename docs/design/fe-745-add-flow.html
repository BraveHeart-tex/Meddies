The same in all three

  • A scan only fills the form. Nothing saves until she presses Save medication.
  • Every scanned value stays editable. The screen asks her to check it against the pack.
  • Camera off: "Camera is off for Meddies. Turn it on in iPhone Settings, or type the details."
  • Offline: the existing Connect to save state applies, and barcode lookup waits for a connection.
  • After Save: the existing handoff, 647·A6, with Set schedule and Done for now.

To settle before building

  • More types. The saved unit only allows tablet or capsule today. Each new type needs its own amounts, stock counting and strength wording.
  • Barcode source. Meddies has no lookup data today. A scan needs a table from barcode to name, strength and unit.
  • Barcode types. Turkish prescription packs usually carry a 2D DataMatrix, and supplements an EAN-13. The reader should handle both.
  • Decoder. Safari doesn't ship BarcodeDetector by default, so the installed PWA likely needs a WASM decoder.
  • Torch and vibration. Check torch on her iPhone and hide the button if it's missing. iOS has no web vibration, so the read moment has to be visual.
