Meddies Empty States

Design review

Empty states across Meddies

Meddies has 8 empty states and no shared pattern. Two of them tell her something untrue or leave out what the app already knows. All three options below fix that with the same copy and rules, so the choice is purely visual.

Chosen direction

Option B, Single tile

Revised from Tile trio after review. It keeps the centred structure and replaces the three tiles with one icon on a muted sand background, the same in every state.

What ships today

Recreated from the production classes at phone width. The eighth state, the inline No schedule yet row in the Medications list, already works and stays as it is.

  • Misleading"You're all set" appears when a medication has no schedule.

    The branch only checks that medications exist, so an unscheduled medication gets the all-clear. The fix is a separate state that names it and links to Set schedule.

    today-schedule.tsx:301
  • MisleadingA no-dose day hides the next dose Meddies already knows.

    The snapshot carries the next dose up to a week ahead, but the hero needs a dose today to appear. The empty state should say when the next one is.

    today-schedule.tsx:151 · occurrences.ts:77
  • MisleadingDashed borders mean opposite things.

    In Cozy Care, dashed means incomplete. "You're all set" uses it, and an empty History day looks like a Not logged row. Dashed should mean something is left to do.

    history-day.tsx:180 · readme, Cards
  • Dead endTwo first-run paths stop short.

    Today's Go to Medications lands one tap before the add drawer. History offers no way forward when nothing is set up.

    today-schedule.tsx:296 · history-day.tsx:85
  • InconsistentNo two states share an anatomy.

    Headings come in four treatments (none, 16, 19, 24px) and actions in four placements. Medications also shows two berry buttons, against the one-primary rule.

    medications-header.tsx:35
  • Out of scopeNot-found screens are recovery, not empty states.

    The app's 404 uses Alert and the medication version hand-rolls a dashed card. Move the medication version to Alert so both match. History's invalid-date notice is already right.

    not-found.tsx · medication-sub-screen.tsx:86

One pattern, three kinds

Every empty state answers what's here, why, and what to do next. The options only change how that looks.

Start

Nothing set up

Needs one primary action.

Finish

One step missing

Names the medication. Needs one primary action.

Clear

Nothing due, and that's correct

No action. Says what comes next when known.

  • Dashed only when something is left to do.
  • At most one primary action. Header Add goes soft while the list is empty.
  • Show only after the read finishes. Failed reads stay Alerts.
  • Several unscheduled medications: name none, action reads Open Medications.
